## Descripción de la Página Web
Es un catálogo de productos realizado en Visual Studio Code utilizando HTML y CSS para mostrar diferentes artículos de manera organizada y atractiva.

## Descripción de la Tarjeta Diseñada
Cada tarjeta está diseñada como un contenedor con borde y sombra que presenta la imagen del producto, su nombre, descripción, precio y un botón de acción.
